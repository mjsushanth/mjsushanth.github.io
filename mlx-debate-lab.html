mlx-debate-lab: Multi-Agent LLM Debate on Apple Silicon

Local multi-agent LLM debate system orchestrated with LangGraph and the Model Context Protocol, running entirely on Apple Silicon (24 GB unified memory) against ~34 GB of model weights with no API calls. Two models argue a motion across three rounds, grounded in evidence retrieved from a real IR corpus and scored by sixteen parallel judge workers. The primary contribution isn't debate quality — it's nine documented failure modes, each of which ran cleanly, returned a value, and was wrong.
  • Graph Orchestration: LangGraph state machine — 13 nodes, three conditional-edge patterns (gate, cycle, Send fan-out to 16 judge tasks), recursion limit derived rather than guessed (72 for 5 rounds), checkpoint resume proven against a forced crash
  • MCP Protocol Layer: Two production servers, 9 tools and 7 resources, with stdio/HTTP transport equivalence proven live via raw curl — HTTP overhead measured at 1.5x, cold stdio subprocess at 194x
  • MLX Memory Engineering: Phase-separated residency — debaters (17.2 GB), judges (16.6 GB), never co-resident — fits ~34 GB of weights in 24 GB of unified memory. Prompt caching and batch_generate were both measured and rejected (−5.2% TTFT; 3 failures across 2 architectures)
  • Hybrid Evidence Retrieval: BM25, dense embeddings, and RRF fusion over a 14,195-document corpus, with nDCG@k, Recall@k, and MRR implemented from scratch. A compression step cuts ~8,262 retrieved tokens to ~150 before they reach a debater — hybrid retrieval lost to plain BM25 (0.6334 vs 0.6413 nDCG@10)
  • Failure-Mode Instrumentation: Every generation is classified at the model boundary (EMPTY, TRUNCATED, MARKER_LEAK, PARSE_FAIL, DIMENSION_MISMATCH), full raw output retained. Caught 9 real defects this way — including an evidence path that ran cleanly while producing zero effect
  • Experimental Rigor: 63 of 70 pre-registered acceptance gates passed. Ablations run at temperature 0 behind validity gates that void a run outright for identical transcript hashes across arms, or zero citations on an evidence-enabled run
  • Engineering & Documentation: 8,481 lines, 89 tests, ruff-clean, 4 executed notebooks, 15 documentation guides, and a 26-entry decision log tagging each choice as forced or judgment
