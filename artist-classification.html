Artist Classification

Comparative analysis of SVM-SIFT-BoVW, Convolutional Autoencoders, Variational Autoencoders, and CNNs (ResNet-50, VGG-16) for artistic style classification on 8,774 artworks from 50 artists. The classical SVM approach reached 89.2% accuracy, showing that texture-based features outperform semantic understanding for art classification.
  • SVM-SIFT-BoVW Pipeline: Extracted SIFT features and built a Bag of Visual Words model with K-means (500 visual words from 6,858 training images), turning each image into a fixed-length histogram for classification.
  • Multi-Level Feature Engineering: Combined SIFT BoVW histograms with Local Binary Pattern descriptors (24 neighbors, radius 8) that encode brush strokes and surface texture, plus one-hot encoded metadata (genre reached 89.2% accuracy, nationality 58.06%).
  • Classical vs Deep Learning Comparison: The SVM (89.2% test accuracy, macro F1 0.831) clearly outperformed ResNet-50 (58.64% on an 11-artist subset), VGG-16 (54.69%) and Convolutional Autoencoders. Texture and brush-stroke patterns proved more discriminative than high-level semantics for style.
  • Model Analysis and Insights: Most misclassifications came from 19th century French artists with similar impressionist styles (overall precision 0.857, recall 0.827), so closely related movements are the weak spot while most of the 50 classes held up well.
  • Architecture Experimentation: Evaluated unsupervised feature learning with Convolutional Autoencoders, using SMOTE balancing and inverse weighting on 2,660 images from 5 artists. Supervised models with hand-crafted features did better on this low-volume dataset.
